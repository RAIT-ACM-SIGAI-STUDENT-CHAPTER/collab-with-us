# 🧩 Contributing Guide — Collab With Us (RAIT ACM SIGAI)

Welcome, contributor\! 🎉
We’re thrilled that you want to contribute to **RAIT ACM SIGAI’s “Collab With Us”** initiative — where students build, learn, and innovate together.

This guide will help you **create, structure, and submit** your project contributions effectively.

-----

## Proposals vs. Code

### 💡 For Project Proposals

We **do not** use Pull Requests (PRs) for new project proposals.

Instead, we use **GitHub Issues**. This is the simplest way to get your idea on the board.

Please see the **"How to Propose a Project"** section in our main `README.md` file for the easy, step-by-step instructions.

### 💻 For Repository Code

This repository is primarily for project proposals, not for active code development. We are not actively accepting Pull Requests to change the repository's code or structure at this time.
