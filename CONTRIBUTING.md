# 🧩 Contributing Guide — Collab With Us (RAIT ACM SIGAI)

Welcome, contributor\! 🎉
We’re thrilled that you want to contribute to **RAIT ACM SIGAI’s “Collab With Us”** initiative — where students build, learn, and innovate together.

This guide will help you **create, structure, and submit** your project contributions effectively.

-----

## 🚀 Quick Start

1.  **Fork** the repository
    Click the top-right **Fork** button on GitHub.

2.  **Clone your fork**

    ```bash
    git clone https://github.com/<your-username>/collab-with-us.git
    cd collab-with-us
    ```

3.  **Create a new branch**
    Use a clear branch name related to your contribution:

    ```bash
    git checkout -b feature-your-project-name
    ```

    *Examples:*

      * `feature-ai-resume-analyzer`
      * `update-project-guidelines`
      * `fix-contribution-typo`

4.  **Add your project proposal**

      * Go to: `PROJECTS/`
      * Create a new file: `PROJECTS/<your_project_name>.md`
      * Follow the project proposal format:

    > # 🧠 Project Title

    > ## 💡 Problem Statement

    > Briefly describe what problem this project solves.

    > ## 🎯 Objective

    > What’s the goal or expected outcome?

    > ## 🧰 Tech Stack

    > List technologies or frameworks you plan to use (e.g., Python, TensorFlow, React, FastAPI).

    > ## 👥 Team Members

    >   - Name 1 (Role)
    >   - Name 2 (Role)
    >   - Optional mentors

    > ## 🚀 Expected Output

    > What will this project produce? (App, Model, API, Paper, etc.)

    > ## 🧩 Contribution Opportunities

    > Suggest areas others can help with — UI, backend, data collection, model tuning, docs, etc.

5.  **Commit your changes**

    ```bash
    git add .
    git commit -m "Added new project: <project-name>"
    ```

6.  **Push your branch**

    ```bash
    git push origin feature-your-project-name
    ```

7.  **Submit a Pull Request (PR)**

      * Go to your fork on GitHub → Compare & Pull Request
      * Add a short, clear title (e.g., “Added new ML project proposal”)
      * Provide a brief summary in the PR description

-----

## 🧭 Contribution Rules

  - Follow clean code and commit message conventions.
      * ✅ **Good:** `feat: added AI project proposal template`
      * ❌ **Bad:** `stuff added`
  - Each PR should focus on one change or project — small, reviewable, and clear.
  - Keep your proposals original and relevant to AI, ML, data, or interdisciplinary innovation.
  - Always respect the **Code of Conduct**.
  - Be kind and collaborative in all reviews or discussions. ❤️

-----

## 🧠 Optional: Working on Existing Projects

If you want to contribute to an existing project:

  - Go to the project’s folder inside `/PROJECTS/`.
  - Check the open Issues for that project.
  - Comment on the issue (e.g., “I’d like to take this up\!”).
  - Wait for approval from project maintainers before pushing changes.

-----

## 🏅 Recognition

Outstanding projects that are successfully developed and presented by students may be featured on our official RAIT ACM SIGAI social media channels and website.

**Recognition is based on the completed project, not just the proposal here.**

-----

## 🧩 Need Help?

If you’re stuck:

  - Raise an **Issue** in the repository describing your question.
  - Or tag mentors / maintainers using `@rait-acm-sigai` on GitHub.
